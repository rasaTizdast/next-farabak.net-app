# Investigation evidence

Collected on 20 November 2026 for [the investigation report](../../seo-crawlability-audit.md). HTTP server dates are UTC; the user-facing investigation date is Asia/Tehran.

| Files                                                       | Provenance and scope                                                                                                                                                                                                                                                             |
| ----------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `http-baseline.json`                                        | Local Windows curl GET/HEAD, redirect headers, timings, TLS verification result and short body samples. A successful final 200 can follow a redirect; inspect the saved header chain.                                                                                            |
| `bot-accept-tests.json`                                     | Local curl requests with 12 representative browser/bot strings, deeper four-agent probes, and two Markdown Accept combinations. These are not authentic crawler-source requests.                                                                                                 |
| `html-content.json`, `bot-stream-content.json`              | Parsed complete HTTP bodies, excluding script/style text. Hidden-ancestor counts distinguish transported content from immediately visible markup. This is not a JS-disabled browser screenshot.                                                                                  |
| `supplement-http.json`, `supplement-content.json`           | Additional catalog/blog/private/404/alias probes and three competitor origins, robots and sitemap responses. Competitor metadata/content is public evidence, not an endorsement of its claims.                                                                                   |
| `dns-public-resolvers.json`, `dnssec-soa.json`              | DNS queries addressed to three public resolvers from this local network; DNSSEC record/header observations do not constitute a full independent cryptographic audit.                                                                                                             |
| `dns-doh.json`                                              | Failed attempted DoH transports. These failures must not be reported as Farabak DNS failures.                                                                                                                                                                                    |
| `curl-ipv4.json`, `curl-ipv6.json`, `tls.json`, `ping.json` | IPv4/IPv6 curl outcomes, verified Python TLS handshakes/certificate details, and two timed-out ICMP requests. Local client IP metadata was removed.                                                                                                                              |
| `remote-checks-start.json`, `remote-checks-results.json`    | Check-Host API request IDs, public report links, selected nodes and actual results for three resources across seven countries. Probe-location labels come from that service. These are point-in-time tests.                                                                      |
| `sitemap-urls.json`                                         | 485 URLs parsed from the production XML; not evidence that all 485 destinations were crawled in this audit.                                                                                                                                                                      |
| `gsc-*.json`                                                | First-party Google Search Console results read through the connected OpenSEO project. `siteUrl` identifies the actual property: `https://farabak.net/`. Date ranges are Google/Pacific reporting dates. URL Inspection reads stored index state and can predate today's release. |
| `observation-notes.json`                                    | Explicitly labeled user-reported timeline, rendered-browser observations, web-tool retrieval/cache behavior and the stopped Chrome inspection. Notes are not invented HTTP/log results.                                                                                          |
| `source-fingerprints.json`                                  | SHA-256 fingerprints for 23 inspected repository entry points at commit `a32f9d03`; no environment secret values were read or fingerprinted.                                                                                                                                     |

The `gsc-daily.json` property/date totals are used for sitewide comparisons. Page and query aggregations have different coverage/aggregation and do not replace those totals. Query rows omit anonymized queries. November 17 is the final date in the saved finalized performance data; it cannot measure the November 19 Germany migration.

The report contains reproduction commands and recommended future tests. Original raw public response bodies were retained in a temporary local diagnostic directory during analysis; the durable JSON files preserve the parsed content, headers and outcomes needed for this report. No authenticated hosting logs, provider-specific failed-request traces, aggregate Search Console UI reports or Bing reports were obtained.

No source fixes, DNS/hosting changes, indexing requests, scheduled jobs, paid services or production deployments were performed. These artifacts contain no required credentials/cookie values; response Set-Cookie values were redacted. Keep first-party search performance exports within the repository's intended audience.
